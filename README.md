# 校了さん TEST — スケジュール・空き日程・会議（PWA）

「校了さん」の本番アプリに機能を追加する前に、独立して試すための**3画面だけのテスト用Webアプリ**です。

- スケジュール
- 空き日程
- 会議

**Firebaseへの接続・ログイン・3人間の同期は、このテスト版にはありません。** 入力内容はブラウザ（PWA）の `localStorage` に保存します。既存の本番用 `koryosan` のデータには触れません。

## 1. GitHub Pagesに公開

公開先として予定しているリポジトリ名：`koryosan-test`

1. `Koryosan_Test_PWA_GitHubPages.zip` を解凍します。
2. GitHubで `https://github.com/kaiutsunomiya-jpg/koryosan-test` を開きます。まだ存在しなければ、`koryosan-test` という新しい **Public** リポジトリを作成します。
3. Code → Add file → Upload files を開きます。空のリポジトリなら `uploading an existing file` を押します。
4. 解凍した `Koryosan_Test_PWA` フォルダの**中にある `index.html`、`app.js`、`styles.css`、`sw.js`、`manifest.webmanifest`、`icons/` のすべて**をルートにアップロードします。ZIP自体や外側フォルダはアップロードしません。
5. `Commit changes` を押します。
6. `Settings → Pages → Build and deployment` で、`Deploy from a branch` / `main` / `/(root)` を選びます。
7. `Actions` で公開に成功したら、下記を開きます。

`https://kaiutsunomiya-jpg.github.io/koryosan-test/`

iPhoneのSafariで開いて「共有 → ホーム画面に追加」にすると独立したアプリとして利用できます。最初にオンライン状態で開けば、Service Workerがファイルをキャッシュし、以後オフラインでも利用できます（キャッシュが端末から消去された場合を除きます）。

## 2. 画面仕様

### スケジュール

- 予定は**1行目が項目・日付・時間・場所の4カラム、2行目が備考**です。
- 項目：`💪練習`＝黄色、`🎸ライブ`＝薄赤、`🥟その他`＝緑。
- 日付は端末のカレンダー選択（`type=date`）、時間は **00:00から23:55まで5分単位の選択**。
- 備考は入力内容の行数に合わせて自動で高さが変わります。
- 右上＋で追加、ゴミ箱で削除。削除時は「削除しますか？」と確認します。
- 予定を日付・開始時間順に表示します。スマホでは4列を崩さず**カード内を左右にスクロール**して、場所や終了時間を表示できます。画面全体は縦にスクロール可能。
- 初期サンプル（2026年に設定）：
  - `12/17` 19:00–22:00 新宿NOAH（繋ぎとかの練習／セトリ通し）
  - `12/22` 19:00–22:00 渋谷ペンタシティサイド（セトリ集中通し）

### 空き日程

- `日付｜曜日｜🐧｜🦉｜🦜` の5カラムです。入力はどのセルにも自由記述。
- **初回表示時は、その端末の「今日」が表の先頭**に表示されます。上方向にスクロールすれば過去、下方向なら未来に移動できます。必要に応じて日付行を自動で追加します。
- 上部のカレンダーで任意の日へジャンプできます。「今日」ボタンで戻れます。
- 初期入力はすべて空欄です。

### 会議

- タイトルは濃い青色のヘッダー、内容は自由記述欄の行で構成。
- 右上＋で新しい議題を追加します（新規議題の内容欄は1行）。
- 各議題の「＋ 行を追加」で自由記述欄を追加できます。各行は削除でき、議題全体も削除できます。削除前に確認が出ます。
- タイトル・内容とも直接編集可能で、内容量に合わせてテキスト欄が伸びます。
- 初期サンプル「アー写真」は、依頼にあった3つの自由記述欄を収録しています。

## 3. 保存・バックアップ

- 全画面の入力は**その端末のブラウザ内に自動保存**されます（`localStorage`）。Firebase接続や通信送信はしません。
- ページ右上の **「…」** →「JSONバックアップを保存」で全データをファイルとして保存できます。別端末で「JSONバックアップを読み込む」ことも可能です（読み込むと既存のテストデータを置き換えます）。
- 「初期サンプルに戻す」では、確認後に端末内のテストデータをリセットします。
- ブラウザのサイトデータ削除・PWA削除・機種変更でデータが失われる可能性があります。バックアップを推奨します。
- **3人同時編集は不可**です。将来本番版へ取り込む際に、必要な部分をFirebase Realtime Databaseの共有ノードへ移行します。
